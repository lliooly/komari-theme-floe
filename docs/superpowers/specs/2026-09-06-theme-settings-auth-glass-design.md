# Floe 主题设置鉴权与毛玻璃卡片设计

## 1. 背景与目标

Floe 的自定义设置页现在已经嵌入 Komari 后台。需要进一步确认游客不能看到或提交主题管理控件，并让设置页中的卡片和主页使用同一套毛玻璃表现。

## 2. 设计

### 2.1 鉴权边界

- `ThemeSettingsPage` 等待 `/api/me` 返回后再决定页面状态；请求期间只显示加载状态。
- `/api/me` 返回非登录或请求失败时只显示无权限提示，不渲染任何设置控件。
- `ThemeSwitcher` 的 `page` 模式增加自身管理员保护，避免被其他页面误用时暴露管理控件。
- 所有保存继续通过 `/api/admin/settings`，服务端鉴权是最终安全边界；游客在主页弹出面板中的修改仍然只属于本地覆盖，不改变服务器配置。

### 2.2 毛玻璃卡片

设置页的每个分组卡片和无权限/加载状态卡片都标记为 `data-card-blur-surface="true"`。主页已有的全局 CSS 会据此应用背景透明度、模糊、渐变高光和阴影。

卡片表现跟随现有的“卡片模糊”开关、类型、透明强度和额外模糊强度。关闭开关时不强制改变用户的主题设置；开启后主页与设置页使用同一套 CSS 变量。

## 3. 验证标准

- 未登录访问 `/settings` 或 `/settings?embedded=1` 时只显示无权限提示。
- 管理员仍可看到完整设置页并保存配置。
- 页面模式 `ThemeSwitcher` 在非管理员状态下不返回设置表单。
- 设置页所有外层卡片均接入共享毛玻璃 surface 标记。
- 卡片模糊开关关闭/开启时，设置页和主页的卡片表现同步。
- `npx tsc --noEmit`、变更文件 ESLint、静态构建和主题打包通过。
